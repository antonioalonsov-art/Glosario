La Biblioteca de Noreña

INTRODUCCIÓN

Introducción

Las bases de datos son una herramienta fundamental para la gestión eficiente de la información en las organizaciones, ya que permiten almacenar, organizar y recuperar datos de forma estructurada y segura. En el ámbito educativo, una base de datos facilita la gestión de servicios como la biblioteca del centro, permitiendo controlar fondos bibliográficos, usuarios y préstamos. A través de aplicaciones como Microsoft Access, es posible diseñar tablas relacionadas, realizar consultas, crear formularios e informes que optimizan el trabajo administrativo. A lo largo de esta situación de aprendizaje se estudiarán los conceptos básicos de las bases de datos y su aplicación práctica mediante la creación de una base de datos para la biblioteca del centro, dando respuesta a una necesidad real del entorno educativo.

Objetivos

  • Conocer qué es una base de datos y para qué se utiliza en un contexto real.
  • Aprender cómo se introducen y gestionan datos en una base de datos mediante Microsoft Access.
  • Crear una base de datos para la gestión de la biblioteca del centro.
  • Realizar una infografía digital para explicar cómo introducir nuevos títulos en la base de datos.
  • Elaborar un vídeo donde el alumnado explique el uso de la base de datos de la biblioteca creada.

Duración

5 Sesiones compuestas de dos bloques de 55 minutos cada una. Cada sesión 110 minutos.

Asimismo, se utilizará una lista de cotejo para comprobar el correcto funcionamiento de la base de datos de la biblioteca del centro.

Diccionario de términos

  • Tablas: son la estructura principal de la base de datos y se organizan en filas y columnas. Cada tabla almacena información sobre un mismo tipo de elemento. Por ejemplo, en una base de datos de una biblioteca pueden existir tablas como Libros, Usuarios o Préstamos. Cada tabla contiene datos homogéneos y cumple una función concreta dentro del sistema.

  • Campos: son las columnas de una tabla y representan los distintos datos que se desean registrar. En la tabla Libros, algunos campos habituales pueden ser título, autor, ISBN, editorial o año de publicación. La correcta definición de los campos y de su tipo de dato es fundamental para garantizar la calidad y coherencia de la información almacenada.

  • Registros: corresponden a cada una de las filas de una tabla y representan un elemento concreto. Por ejemplo, cada libro registrado en la biblioteca constituye un registro dentro de la tabla Libros. Cada registro contiene información completa sobre un elemento y se identifica mediante un valor único.

  • Relaciones: permiten vincular la información entre distintas tablas a través de campos comunes. Gracias a las relaciones es posible, por ejemplo, asociar un préstamo con un libro concreto y con una persona usuaria determinada. El uso de relaciones evita la repetición innecesaria de datos y facilita una gestión más ordenada y eficiente de la información.

  • La clave primaria o principal es un campo que identifica de manera única cada registro dentro de una tabla. Este valor no se repite y no puede quedar vacío, lo que garantiza que cada elemento registrado sea diferente del resto. Por ejemplo, en una base de datos de una biblioteca, cada libro puede identificarse mediante un código único o un número de registro.

  • La clave secundaria o foránea es un campo que permite relacionar una tabla con otra, ya que hace referencia a la clave primaria de otra tabla. Gracias a las claves foráneas es posible vincular información, como asociar un préstamo a un libro concreto y a una persona usuaria determinada. El uso correcto de estas claves es esencial para mantener la coherencia y fiabilidad de la base de datos.

  • Las consultas permiten seleccionar y mostrar información específica almacenada en una base de datos, facilitando su análisis y uso en contextos administrativos reales. A través de las consultas es posible filtrar datos, ordenar la información y obtener resultados concretos a partir de uno o varios criterios.

  • Los formularios son una herramienta que facilita la introducción y modificación de datos en una base de datos, ya que presentan la información de forma clara y estructurada, reduciendo errores y agilizando el trabajo.

  • Los informes son una herramienta que permite presentar información de la base de datos de forma ordenada, clara y con un formato profesional. A diferencia de las tablas (que están pensadas para almacenar datos) o las consultas (que sirven para filtrar y seleccionar información), los informes se utilizan para mostrar resultados de manera comprensible, lista para imprimir o compartir.
