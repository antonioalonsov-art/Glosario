1. Las Bases de Datos

Las bases de datos son sistemas que permiten almacenar, organizar y gestionar información de forma estructurada con el objetivo de facilitar su uso y recuperación. En el ámbito administrativo y educativo, una base de datos se utiliza para gestionar grandes volúmenes de datos de manera eficiente, por ejemplo, el catálogo y los préstamos de una biblioteca.

En el diseño de una base de datos se pueden distinguir tres niveles fundamentales: nivel conceptual, nivel lógico y nivel físico.

El nivel conceptual define qué información se necesita y cómo se relaciona, sin entrar en aspectos técnicos. En el caso de una biblioteca, incluye elementos como libros, usuarios y préstamos, así como las relaciones entre ellos.

El nivel lógico describe cómo se estructura la información dentro de la base de datos. En este nivel se diseñan las tablas, los campos, las claves primarias y las relaciones entre tablas. Por ejemplo, una tabla de libros con sus datos (título, autor, ISBN) relacionada con una tabla de préstamos.

El nivel físico hace referencia a cómo se almacenan los datos en el sistema informático y al software utilizado para gestionarlos. En esta situación de aprendizaje, el nivel físico se materializa mediante el uso de Microsoft Access como sistema de gestión de bases de datos.

Uno de los aspectos clave en el diseño de una base de datos es garantizar su calidad y mantenimiento a lo largo del tiempo. Al igual que los productos evolucionan, las bases de datos deben adaptarse a nuevas necesidades, como la incorporación de nuevos títulos, usuarios o funcionalidades. Factores como el crecimiento del volumen de datos, la actualización de la información o los cambios en las necesidades del centro influyen directamente en la evolución y mejora de la base de datos.


2. Elementos de las Bases de Datos

En una base de datos relacional, como las creadas con Microsoft Access, se distinguen varios elementos fundamentales que permiten organizar la información de forma estructurada y eficiente. Estos elementos hacen posible almacenar datos relacionados entre sí, facilitar su consulta y evitar errores o duplicidades en la información.

  • Tablas: son la estructura principal de la base de datos y se organizan en filas y columnas. Cada tabla almacena información sobre un mismo tipo de elemento. Por ejemplo, en una base de datos de una biblioteca pueden existir tablas como Libros, Usuarios o Préstamos. Cada tabla contiene datos homogéneos y cumple una función concreta dentro del sistema.
  • Campos: son las columnas de una tabla y representan los distintos datos que se desean registrar. En la tabla Libros, algunos campos habituales pueden ser título, autor, ISBN, editorial o año de publicación. La correcta definición de los campos y de su tipo de dato es fundamental para garantizar la calidad y coherencia de la información almacenada.
  • Registros: corresponden a cada una de las filas de una tabla y representan un elemento concreto. Por ejemplo, cada libro registrado en la biblioteca constituye un registro dentro de la tabla Libros. Cada registro contiene información completa sobre un elemento y se identifica mediante un valor único.
  • Relaciones: permiten vincular la información entre distintas tablas a través de campos comunes. Gracias a las relaciones es posible, por ejemplo, asociar un préstamo con un libro concreto y con una persona usuaria determinada. El uso de relaciones evita la repetición innecesaria de datos y facilita una gestión más ordenada y eficiente de la información.

3. Tipos de Bases y usos

Existen distintos tipos de bases de datos según su finalidad, tamaño y nivel de complejidad. La elección de un tipo u otro depende de las necesidades de gestión de la información y del contexto en el que se vaya a utilizar.

  • Bases de datos personales o locales: se utilizan para gestionar información en un solo equipo o en pequeños entornos de trabajo. Son habituales en contextos educativos o administrativos sencillos y permiten un manejo directo y accesible de los datos. Un ejemplo de este tipo de bases de datos es Microsoft Access, que facilita la creación de tablas, consultas, formularios e informes sin necesidad de conocimientos avanzados de programación.

  • Bases de datos corporativas: están diseñadas para gestionar grandes volúmenes de información y suelen ser utilizadas por empresas y organizaciones de mayor tamaño. Permiten el acceso simultáneo de múltiples personas usuarias y requieren sistemas de gestión más complejos y servidores específicos para garantizar la seguridad y el rendimiento.


En esta situación de aprendizaje se trabajará con una base de datos local, diseñada específicamente para la gestión de la biblioteca del centro, ya que se adapta a las necesidades planteadas y permite al alumnado comprender de forma práctica los fundamentos del tratamiento de la información.

4. Evolución y mantenimiento de una base de datos

Una base de datos no es un sistema estático, sino que evoluciona y se adapta con el tiempo a las necesidades de la organización que la utiliza. En el caso de una biblioteca, será necesario incorporar nuevos títulos, actualizar la información existente, eliminar registros obsoletos o modificar la estructura de la base de datos para mejorar su funcionamiento.


El crecimiento del volumen de datos, los cambios en el uso del servicio o la incorporación de nuevas funcionalidades influyen directamente en la evolución de la base de datos. Por este motivo, es fundamental realizar un mantenimiento periódico que garantice la coherencia, actualización y fiabilidad de la información almacenada. Un buen diseño inicial facilita estas tareas y permite que la base de datos siga siendo útil y eficiente a lo largo del tiempo.

5. ¿Qué vais a hacer en esta situación de aprendizaje?

En esta situación de aprendizaje vais a trabajar con bases de datos y aprenderéis a utilizar Microsoft Access para crear una base de datos real destinada a la biblioteca del centro. A lo largo de las sesiones iréis diseñando y mejorando la base de datos, aprendiendo a introducir información, organizarla correctamente y utilizarla de forma práctica.


Al finalizar el proyecto, elaboraréis dos productos finales que os permitirán demostrar lo aprendido y crear recursos útiles para el centro.

Producto final 1: Infografía interactiva
Realizaréis una infografía digital en la que explicaréis, de forma clara y visual, cómo se introducen nuevos libros en la base de datos de la biblioteca. En la infografía se mostrarán los pasos que hay que seguir en Microsoft Access para añadir correctamente la información, de manera que cualquier persona pueda entender cómo hacerlo.

Producto final 2: Vídeo explicativo
Elaboraréis un vídeo en el que explicaréis cómo funciona la base de datos de la biblioteca que habéis creado. En el vídeo mostraréis su uso básico y para qué sirve, ayudando a comprender cómo se puede utilizar para gestionar los libros y los préstamos.
