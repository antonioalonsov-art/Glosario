SESIÓN 4: Informes y Seguridad

Objetivos

  •  Comprender la utilidad de los informes para presentar información de forma clara y profesional.
  • Aprender a crear informes en Microsoft Access aplicados a la base de datos de la biblioteca del centro.
  • Exportar datos e informes a formatos habituales (PDF y hoja de cálculo) según necesidades de gestión.
  • Conocer medidas básicas de seguridad y mantenimiento para proteger y conservar la base de datos.
  • Revisar y finalizar la base de datos del proyecto, comprobando su correcto funcionamiento mediante una lista de control.

1. Informes profesionales: para qué sirven y cuándo se usan

Los informes son una herramienta que permite presentar información de la base de datos de forma ordenada, clara y con un formato profesional. A diferencia de las tablas (que están pensadas para almacenar datos) o las consultas (que sirven para filtrar y seleccionar información), los informes se utilizan para mostrar resultados de manera comprensible, lista para imprimir o compartir.


En el contexto de la biblioteca del centro, un informe puede servir para elaborar listados como: libros disponibles, libros prestados, préstamos por fechas, o registros por categorías. Diseñar informes adecuados mejora la organización y facilita la toma de decisiones, ya que permite disponer de información útil sin necesidad de buscar registro por registro.

2. Creación guiada de informes en Microsoft Access

Para crear un informe en Access se parte normalmente de una tabla o consulta. Esto permite generar documentos con datos ya filtrados y presentarlos de forma profesional. Durante esta sesión se trabajará la creación de distintos tipos de informes, prestando atención a:

  • Estructura (título, encabezados, secciones y agrupaciones)
  • Orden y formato (alineación, tipos de letra, tamaños y márgenes)
  • Claridad (campos relevantes, etiquetas comprensibles y coherencia visual)

El objetivo es que el alumnado aprenda a generar informes que puedan usarse en una gestión real de la biblioteca, cuidando la presentación y la utilidad del documento.

3. Exportación de datos: compartir información en otros formatos

En muchos entornos administrativos es necesario compartir información fuera de Access. Por ello, se trabajará la exportación de datos e informes a formatos habituales:

  • PDF, para compartir informes con un formato estable y listo para imprimir.
  • Hoja de cálculo, para trabajar con datos, realizar cálculos o compartir información con otras aplicaciones.

En esta sesión se explicará cómo exportar correctamente y cómo comprobar que el resultado mantiene el formato y la información necesaria. La exportación es una habilidad muy útil para la comunicación y la gestión documental.

4. Seguridad básica, mantenimiento y cierre del proyecto

Una base de datos contiene información que debe gestionarse con cuidado. Por eso, en esta sesión se abordarán medidas básicas de seguridad y mantenimiento, como:

  • Realizar copias de seguridad periódicas.
  • Controlar el acceso al archivo y evitar modificaciones no deseadas.
  • Mantener la base de datos ordenada y coherente, revisando duplicidades y errores de introducción de datos.
  • Verificar que tablas, relaciones, consultas, formularios e informes funcionan correctamente.

Finalmente, el alumnado realizará una revisión y finalización del proyecto utilizando una lista de control, comprobando que la base de datos de la biblioteca está completa, funciona correctamente y cumple los requisitos establecidos.
